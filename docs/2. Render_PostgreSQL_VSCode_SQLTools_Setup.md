# Connect Render PostgreSQL to VS Code with SQLTools

## 1. Install the VS Code extensions

1. Open VS Code.
2. Press **Ctrl + Shift + X** to open Extensions.
3. Search for **SQLTools** (publisher: Matheus Teixeira) and install it.
4. Search for **SQLTools PostgreSQL/Cockroach Driver** and install it.
5. Open the **SQLTools** sidebar (database icon).

## 2. Create a connection

1. In SQLTools, choose **Add New Connection**.
2. Select **PostgreSQL**.
3. Set the following fields:

| Field | Value |
|---|---|
| Connection name | `Render PostgreSQL` |
| Connection group | Leave blank (optional) |
| Connect using | `Server and Port` |
| Server Address | `dpg-dbfojtks728c738hehs0-a.oregon-postgres.render.com` |
| Port | `5432` |
| Database | `atlas_fde` |
| Username | `atlas_user` |
| Use password | **Ask on connect** (recommended) |
| SSL | **Enabled / Required** (see next section) |
